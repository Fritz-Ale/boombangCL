Información de privacidad — versión de desarrollo

Este texto describe las funciones de software del proyecto y no es una política legal definitiva de un servicio publicado.

¿Qué información utiliza el portal?

Para crear una cuenta: nombre de usuario, correo electrónico y hash de contraseña. Para las funciones sociales: temas del foro, respuestas, mensajes de chat, solicitudes de amistad, pertenencia a clanes, invitaciones y reportes de contenido.

¿Se comparten contraseñas con otros usuarios?

No. La aplicación utiliza hashes de contraseña en Laravel. El portal no debe mostrar contraseñas ni tokens internos. No publiques tu contraseña en mensajes o temas.

¿Se informa cuántos jugadores hay conectados?

La API puede consultar únicamente el número de usuarios autenticados conectados al servidor del juego, sin sus nombres. El portal también registra actividad reciente de cuentas autenticadas para calcular una cifra separada.

¿Cómo se gestionan cookies y sesiones?

El inicio de sesión web usa una cookie de sesión de Laravel y protección CSRF. La configuración de HTTPS, el dominio, la duración y la seguridad de cookies deben revisarse al desplegar.

¿Puedo eliminar mis datos?

Actualmente no existe un control público de eliminación de cuenta. Un lanzamiento requerirá un procedimiento verificado de acceso, rectificación y eliminación, teniendo en cuenta los datos del juego y obligaciones legales aplicables.

¿Existen pagos?

Las compras y pagos web no están habilitados; el portal no recopila tarjetas ni datos de cobro.

Antes de publicar: definir responsable del tratamiento, medio de contacto real, retención de datos, solicitudes de usuarios, medidas de seguridad y textos legales conforme a la jurisdicción aplicable. No se ha inventado una dirección de contacto.
