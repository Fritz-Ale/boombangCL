ANTES DE ENTRAR

¿Cómo puedo jugar?

La experiencia multijugador necesita que el cliente HTML5 se comunique con el servidor, la API y la base de datos del proyecto.

  1. Revisa los requisitos.

    Instala Git y Docker Desktop en tu Mac. El proyecto usa Docker Compose y servicios separados.

  2. Configura el entorno.

    Clona el repositorio, crea los archivos .env desde los ejemplos y configura la red y los dominios de desarrollo que indica el README principal.

  3. Inicia los servicios.

    Desde la raíz del repositorio, ejecuta los contenedores y configura la base de datos y Laravel Passport siguiendo la documentación técnica.

  4. Abre el cliente.

    Con los dominios locales resueltos y todos los servicios activos, visita la URL de desarrollo del cliente.

PREGUNTAS FRECUENTES

Lo esencial

¿Puedo crear una cuenta desde aquí?

El portal incorpora formularios de registro y acceso con sesiones web y CSRF de Laravel. Funciona al configurar la API, las migraciones y la base de datos. Para entrar al cliente HTML5 todavía debes iniciar sesión dentro del juego.

¿Hay usuarios conectados ahora?

El chat puede mostrar una estimación de usuarios activos del portal durante los últimos 5 minutos. Eso NO significa que estén conectados al juego: no hay una API verificada para ese contador.

¿Es una copia oficial de BoomBang.tv?

No. Es una implementación original e independiente inspirada en las categorías generales de una comunidad de juego, basada en el repositorio BoomBang HTML5.

¿Funciona en Mac?

La plataforma web y los servicios Docker pueden prepararse en macOS. El launcher de Electron documentado en la base está orientado a Windows, pero el cliente HTML5 es para navegador.
