TE CONTAMOS MÁS

Preguntas
de la isla.

Lo que conviene saber antes de comenzar tu aventura.

¿Qué es BoombangCL?+

Es un proyecto independiente de recuperación y continuidad de BoomBang HTML5, con cliente web, API y servidor multijugador.

¿Es la web oficial de BoomBang?+

No. BoombangCL es independiente, no está afiliado ni respaldado por los titulares originales de BoomBang.

¿Ya puedo registrarme o jugar desde esta web?+

Esta versión es una portada informativa. El registro y el acceso no están integrados aquí. El botón de juego abre la dirección local del cliente y requiere que los servicios estén configurados.

¿Puedo seguir el desarrollo?+

El código y la documentación se mantienen en el repositorio BoombangCL de GitHub. Algunas funciones podrán cambiar durante el desarrollo.
