Para jugar en tu Mac debes iniciar los servicios del cliente HTML5, Laravel, Socket.IO y la base de datos. La web pública aún no ofrece acceso al juego. Consulta la guía del repositorio antes de intentar entrar.

TE CONTAMOS MÁS

Preguntas
de la isla.

Lo que conviene saber antes de comenzar tu aventura.

¿Qué es BoombangCL?+

Es un proyecto independiente de recuperación y continuidad de BoomBang HTML5, con cliente web, API y servidor multijugador.

¿Es la web oficial de BoomBang?+

No. BoombangCL es independiente, no está afiliado ni respaldado por los titulares originales de BoomBang.

¿Ya puedo registrarme o jugar desde esta web?+

Esta versión es una portada informativa. El registro y el acceso no están integrados aquí. El botón de juego abre la dirección local del cliente y requiere que los servicios estén configurados.

¿Puedo seguir el desarrollo?+

Consulta la hoja de ruta y el repositorio de GitHub. Las funciones aún pueden cambiar durante el desarrollo.

¿BoomBangCL es una comunidad oficial de BoomBang.tv?+

No. Es un proyecto independiente inspirado en los juegos sociales clásicos, con su propia comunidad y sin afiliación con BoomBang.tv.

¿Ya existe un dominio .cl y un servidor público disponible?+

El portal se está preparando para un futuro dominio .cl; aún no se confirma que el dominio esté registrado ni que el juego esté publicado.
