# BoomBangCL — publicación independiente

Este directorio conserva el prototipo HTML/CSS/JS aprobado sin alterar la aplicación actual de la rama main.

Cloudflare Pages: https://boombangcl.pages.dev
Rama de producción: site/boombangcl-prototipo-20261112
Comando de build: node boombangcl-release/build.mjs
Salida: boombangcl-release/dist

Las imágenes externas referenciadas por el HTML pueden no estar disponibles o requerir permiso de uso. Los formularios actuales son demostrativos y no están conectados al backend Laravel. Este lanzamiento no modifica el juego, las cuentas ni las bases de datos.
