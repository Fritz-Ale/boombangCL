01 / EL PROYECTO

Preservar su esencia.
Construir lo que sigue.

BoomBang CL es una iniciativa independiente basada en el proyecto de código abierto BoomBang HTML5. Trabajamos sobre el cliente, la API y las herramientas necesarias para documentar y recuperar sus funcionalidades.

La web que visitas es el punto de información pública. Las partidas, las cuentas y las funciones que requieren servidores siguen en desarrollo.
